# Site Institucional e Agendamento - Psicologia Clínica

Uma aplicação web responsiva (Single Page Application - SPA) desenvolvida para centralizar o contato e automatizar o agendamento de pacientes de psicologia clínica, servindo como ponto focal ("Link na Bio") para redes sociais.

## 🎯 O Problema Resolvido
Profissionais da saúde frequentemente perdem horas na conciliação manual de agendas via WhatsApp. Este projeto resolve esse gargalo ao integrar a apresentação profissional da clínica diretamente a um sistema de agendamento automatizado (Calendly), eliminando choques de horário e otimizando o fluxo de novos pacientes.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Semântica e estruturação acessível.
* **CSS3:** Layout responsivo (Mobile-First), Flexbox, variáveis de cor e animações suaves (transitions).
* **JavaScript (Vanilla):** Manipulação do DOM para controle do menu lateral dinâmico (Sidebar / Hamburger Menu).
* **Calendly Widget:** Integração de script externo para sincronização em tempo real com a agenda nativa (iOS/Google).
* **Netlify:** Hospedagem em nuvem e deploy contínuo.

## 📱 Funcionalidades em Destaque
* **Design Responsivo:** Interface otimizada prioritariamente para smartphones (90%+ do tráfego esperado), adaptando-se perfeitamente a monitores desktop.
* **Menu Lateral Dinâmico:** Implementação de navegação em barra lateral controlada por JavaScript puro.
* **UI/UX Focada na Área da Saúde:** Paleta de cores baseada em tons de areia (Off-white) e azul noturno para transmitir serenidade, clareza e credibilidade.
* **Agendamento Self-Service:** Pacientes visualizam em tempo real apenas os horários livres da profissional, agendando a sessão sem necessidade de intervenção humana prévia.
